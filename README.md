# hazemhassine.space

A personal portfolio and blog website built with Next.js, React, and Tailwind CSS.

## Features

- **Portfolio/Projects**: Showcase of personal and professional projects.
- **Blog**: Markdown-powered blog for writing articles.
- **Experience Timeline**: A visual timeline of work experience.
- **Admin Markdown Editor**: Built-in markdown editor for creating content.

## Tech Stack & Tags

tags: `next.js`, `react`, `tailwindcss`, `portfolio`, `blog`

- [Next.js](https://nextjs.org/) (App Router)
- [React](https://reactjs.org/)
- [Tailwind CSS](https://tailwindcss.com/)
- [Framer Motion](https://www.framer.com/motion/)

## Getting Started

First, install dependencies:

```bash
npm install
# or
yarn install
# or
pnpm install
```

Then, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `app/page.js`. The page auto-updates as you edit the file.
